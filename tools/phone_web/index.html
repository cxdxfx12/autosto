运单揽件助手 · 手机端

让手机自己把单号灌进申行者，不用手点
1装 AutoJs6
点下面的按钮下载，装完打开一次，按提示开「无障碍服务」（设置 → 无障碍 → 已下载的服务 → AutoJs6 打开）。
下载 AutoJs6 安装包
2复制探针脚本
先让申行者停在「揽件扫描」页，然后在 AutoJs6 里新建脚本 → 粘贴 → 运行。它会把这一页的控件信息传回电脑，用来配好后续的点按钮动作。
3复制正式脚本
探针跑通后，新建一个脚本，粘贴这个，运行。之后电脑一发批，手机就自己粘贴、点确定、回传结果。
跑之前注意
  1. 手机停在申行者 → 揽件扫描页，别锁屏
  2. AutoJs6 需要「无障碍」+「后台弹窗/悬浮窗」权限，否则会被系统杀掉
  3. 脚本每 3 秒问一次电脑有没有新批次，有就自动干
  4. 界面改了导致认不出按钮，脚本会把当前界面传回电脑，我再调
